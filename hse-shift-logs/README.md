# HSE Night Shift Logs — Project 10265 WASP

Working records for the HSE Advisor night shift (17:30–05:30), Bulk Earth Works, RTIO West Angelas.

| Path | Purpose |
|---|---|
| `open-items.md` | Standing register of live open items. Pruned only when Kevin confirms an item is closed or not his. |
| `YYYY-MM-DD-shift-log.md` | One log per night. Each of Kevin's updates is entered as a formal line (time, entry, status). |
| `handovers/YYYYMMDD-handover.md` | Text copy of each delivered handover, kept for continuity into the next shift/session. |

## Conventions
- Direct evidence only. Record-led wording. No conduct observations, personnel quotes or escalations.
- Quotes are "words to the effect of". "Discomfort", never "pain". Never "injured person" or "mitigate".
- Hazards written asset/location-led (what/where).
- Advisor only: anything action-facing is a forward-up note or draft for the HSE Superintendent / Senior Advisor, never an outbound document in Kevin's name.
- The delivered handover .docx is always built by editing the most recent house-template handover Kevin attaches. The text copy here is for continuity only, not a substitute format.
- Field/office split is the ACTUAL split Kevin reports, not the nominal 70/30.
